# 视频精简 · LSPosed

为腾讯视频、优酷和爱奇艺提供独立的广告拦截与界面精简设置。

**[下载最新版 APK](https://github.com/2909272751/video-lsposed/releases/latest)** · [兼容性与验证范围](docs/COMPATIBILITY.md)

## 功能

| 应用 | 当前功能 |
|---|---|
| 腾讯视频 | 开屏与播放广告拦截、首页顶部轮播隐藏、个人中心广告横幅隐藏、关闭首页片段自动播放；分别控制短剧、会员专区、好物底栏入口 |
| 优酷 | 开屏、广告位及暂停广告拦截；首页与个人中心推广清理；独立底栏选项 |
| 爱奇艺 | 开屏、首页顶部广告与会员促销条、个人中心横幅清理；独立底栏选项 |
| 三个应用共用 | 推送通知广告拦截（只拦会员促销类；追剧提醒、播放、下载通知不受影响） |

三个应用各有独立设置页。兼容结果区分“找到规则”和“实际触发”，并提供失败原因。开关是否生效以实际界面及对应触发记录为准。

腾讯底栏始终保留首页和个人中心。筛选发生在应用校验完成之后，不更改原始缓存；全部显示时不安装该底栏 Hook，没有定时扫描或逐帧遍历。

## 安装与使用

1. 手机需已 Root，并安装支持现代 libxposed API 的 LSPosed；本版本在 Android 16、LSPosed 2.2.0 上验证。
2. 从 Releases 下载并安装 `video-clean-v0.3.12.apk`。
3. 在 LSPosed 启用“视频精简”，在作用域勾选需要使用的应用：腾讯视频、优酷、爱奇艺。安装包提供这三个推荐作用域。
4. 首次启用后重启手机，打开模块设置页，进入对应应用页面设置开关。
5. 修改设置后，强停并重新打开对应应用；回到模块页查看兼容结果与实际触发情况。

腾讯底栏中的“显示”开关：开启保留入口，关闭隐藏入口。重新开启并重启腾讯视频即可恢复，不需要清除腾讯缓存。

## 本地构建

需要 Windows PowerShell、JDK 17、Android SDK（平台 android-35、Build Tools 35.0.0）。可通过环境变量指定安装目录：

```powershell
$env:QLC_JDK = 'C:\path\to\jdk17'
$env:QLC_SDK = 'C:\path\to\android-sdk'
powershell -NoProfile -ExecutionPolicy Bypass -File app/build.ps1
```

产物输出到 `app/dist/`，构建脚本会完成签名与签名校验。省略环境变量时，脚本从项目上级目录的 `.android_build_tools` 查找工具。

`app/debug.keystore` 仅保存在维护者本地，不进入仓库。首次自行构建会创建新的本地签名，因此自编译 APK 不能直接覆盖官方 Release；后续自编译升级请保留自己的密钥。Release 沿用已有签名，可覆盖此前的同签名版本。

源码、资源、编译接口和构建依赖均包含在仓库。第三方组件见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。反编译材料、手机截图、日志与签名密钥不公开。
