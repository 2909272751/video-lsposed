所以启用后**第一行日志就会告诉我们 14 条规则里哪些跨版本活下来了**。

## 需要你做的一步（我做不了，也不该做）

在**新机的 LSPosed 管理器**里启用「腾讯视频精简」，并确认作用域勾选 `com.tencent.qqlive`。
（上次我直接改 lspd 数据库导致过运行态异常，已承诺不再碰。）

具体：LSPosed → 模块 → 腾讯视频精简 → 打开开关 → 作用域里勾选腾讯视频 → 重启腾讯视频。

## 启用后我会立刻做的验证（一条命令即可）

```powershell
& C:\Android\adb.exe shell "su -c 'grep -o \"installs=\[[^]]*\]\" /data/adb/lspd/log/modules_*.log | tail -1'"
```

期望看到形如：
```
installs=[splash_gate=ok … feed_ad_cell=ok … channel_bar=ok channel_bar_tab_v1=ok …]
```
- 若多数 `ok` → 说明跨版本泛适配成立，规则未因 9.03.95 → 9.04.55 漂移；
- 若出现 `miss(...)` → 那就是**版本漂移的精确清单**（每条都自带 reason），据此逐条修锚点。

另外新机需要重新落一次配置（设置页 → 「应用设置到腾讯视频」→ 首次会弹 ColorOS
「允许启动其他应用」，选允许），否则规则会用默认值。
